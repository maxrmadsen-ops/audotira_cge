# Uso

1. Abra `http://127.0.0.1:8080/entrar/`.
2. Entre com um dos usuários de desenvolvimento definidos no `.env`.
3. O painel mostra os indicadores previstos, todos sem dados.
4. Os módulos de prestações, documentos, análises, achados, pré-análises, normas, regras, avaliação e FinOps aparecem como “Em preparação”.
5. O administrador consulta a saúde do sistema e a trilha de auditoria.

Ainda não há upload, extração, regras nem pré-análise.
