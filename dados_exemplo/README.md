# Dados de exemplo

O comando `carregar_cenario_demonstracao` cria o processo fictício `DEMO-2024-001`, marcado como dado de demonstração.

PDFs usados nos testes da inteligência documental são gerados em memória e não são versionados. Resultados do caso real `2022TR000929` só podem surgir do processamento dos documentos reais, que não entram no Git.
